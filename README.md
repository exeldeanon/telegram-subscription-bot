# Бот с проверкой подписки на канал

Бот работает в группе `-1003985789251` и проверяет подписку каждого пользователя на приватный канал `-1002270157899`.

Если подписки нет, сообщение удаляется и бот показывает кнопки «Подписаться на канал» и «Проверить подписку». Уведомление автоматически удаляется через 15 секунд. После подписки пользователь сможет написать следующее сообщение без обязательного нажатия на кнопку проверки.

## Настройка Telegram

1. Откройте `@BotFather`, выполните `/newbot` и сохраните токен.
2. Добавьте созданного бота администратором в группу `-1003985789251` с правом **удалять сообщения**.
3. Добавьте бота администратором в приватный канал `-1002270157899`.
4. Убедитесь, что бот действительно видит канал по этой ссылке: `https://t.me/+NHLJcjDgBIszZTky`.

## Локальный запуск

```bash
python -m venv .venv
python -m pip install -r requirements.txt
copy .env.example .env
# впишите BOT_TOKEN в .env
python bot.py
```

## Размещение на Bothost

Загрузите эти файлы как Python-проект. В переменные окружения Bothost добавьте `BOT_TOKEN`; остальные значения уже указаны в `.env.example`. Команда запуска: `python bot.py`.

Токен бота не публикуйте в чате, GitHub или файлах, доступных другим пользователям.
